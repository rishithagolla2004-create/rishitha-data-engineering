
# Employee Data Analysis Using PySpark

## Project Overview
This beginner-friendly Data Engineering project uses
PySpark to process and analyze employee data.

## Technologies Used
- Python
- PySpark
- Apache Spark
- CSV

## Project Operations
1. Read employee records from a CSV file.
2. Display employee information.
3. Filter employees earning above 40000.
4. Calculate average salary by department.
5. Count employees in each department.

## Project Structure
pyspark-employee-analysis/
    employee_analysis.py
    data/
        employees.csv

## Learning Outcomes
- Reading CSV files using PySpark
- Data filtering
- GroupBy operations
- Aggregate functions
- SparkSession creation
